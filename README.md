## 📥 Installation & Setup

Follow these steps to set up the project locally:

### 1️⃣ Clone the Repository  
```bash
git clone https://github.com/toshit111/Chat-Application.git
cd Chat-Application
```

### 2️⃣ Install Dependencies  
```bash
# For Frontend
cd client
npm install  

# For Backend
cd server
npm install  # or pip install -r requirements.txt (if using Python)
```

### 3️⃣ Run the Application  
```bash
# Start Backend Server
cd server
npm start  # or python app.py

# Start Frontend
cd client
npm start  # or open index.html if pure JS
```

### 4️⃣ Open in Browser  
Go to `http://localhost:3000` (or the port mentioned in your config).
